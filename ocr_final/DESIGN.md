# แนวทางออกแบบหน้าค้นข้อมูลหลักสูตร

## ขอบเขตและอัตลักษณ์

หน้า `/frontend/` ใช้โหมด Operate สำหรับตั้งคำถาม และ Read สำหรับอ่านคำตอบและตรวจหลักฐาน คงภาษาไทย สีเขียว `#1e604c` และ frontend แบบ HTML/CSS/JavaScript เดิม ไม่เปลี่ยนข้อเท็จจริงหรือ API

## การจัดพื้นที่

- desktop ให้พื้นที่ตั้งคำถาม 344px และพื้นที่ที่เหลือกับคำตอบ ไม่บีบทั้งสองฝั่งให้เท่ากัน
- เมื่อความกว้างไม่พอให้อ่านตารางได้ ให้เรียงส่วนตั้งคำถามและคำตอบลงมา และมีลิงก์ข้ามไปคำตอบ
- ตารางมือถือคงรหัส ชื่อ หน่วยกิต รายละเอียด และแหล่งอ้างอิงครบทุกแถว แต่จัดชื่อวิชาเต็มความกว้างใต้รหัสกับหน่วยกิต คง table semantics และหัวตารางสำหรับ assistive technology
- ใช้เส้นแบ่งแผน กลุ่มวิชา และแหล่งอ้างอิง แทนกรอบซ้อนหลายชั้น

## ตัวอักษรและการเข้าถึง

- ใช้ Noto Sans Thai variable font แบบ self-hosted จาก Google Fonts ภายใต้ SIL Open Font License (เก็บ OFL.txt คู่ไฟล์) preload และ font-display:swap; fallback Leelawadee UI/Tahoma/system-ui ไม่เรียกบริการ font ภายนอกขณะใช้แอป ไฟล์เดียวรองรับน้ำหนักที่ใช้จริง
- ใช้ขนาด น้ำหนัก และ line-height แยกบทบาท ไม่เว้นระยะตัวอักษรภาษาไทย หัวข้อกับเนื้อหาใช้ตระกูลเดียวกัน
- body 16px; คำตอบ line-height 1.85 และความยาวบรรทัดไม่เกิน 72ch; รายละเอียดกับ citation ไม่เล็กกว่า 14px
- spacing ใช้หน่วย 4/8/12/16/24/32px; controls และลิงก์ที่ใช้บ่อยมีพื้นที่กดอย่างน้อย 44px
- focus ring สีเขียว 3px ครอบคลุมทุก control, link และ summary รองรับ reduced motion และ forced colors; ไม่ปิดการซูมหรือซ่อน horizontal overflow

## สถานะและความซื่อตรงของข้อมูล

- idle, loading, success, insufficient evidence และ error ใช้ข้อมูลหรือสถานะจริง ไม่ใช้คำตอบจำลอง
- ระหว่าง loading ปิด controls และปุ่มตัวอย่าง ป้องกันคำขอซ้ำ และไม่ส่งคำถามขณะ Thai IME กำลัง composition
- คำตอบแสดงหลักสูตร ฉบับ และคำถามที่ส่งจริง แม้ผู้ใช้เปลี่ยนตัวเลือกหลังได้รับคำตอบ
- validation แจ้งใกล้ช่องคำถาม; network/API error มีปุ่มลองส่งใหม่และเก็บคำถามเดิม
- แสดง PDF page และ printed book page แยกกันเสมอเมื่อมีข้อมูล ไม่เติมหน้าหรือชื่อไฟล์ที่ไม่ทราบ
- citation link สร้างได้เฉพาะชื่อ PDF ที่ endpoint อนุญาตและหมายเลขหน้าเป็นจำนวนเต็มบวก ชื่อไฟล์ต้องมาจาก row หรือองค์ประกอบแรกของ `source.section` ที่ API บันทึกไว้ ไม่อนุมานจากชื่อหลักสูตร
- ข้อมูลทั้งหมดสร้าง DOM ด้วย `textContent`; ไม่แปลงคำตอบหรือ source text เป็น HTML
