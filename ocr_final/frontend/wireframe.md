# โครงร่างหน้าจอปัจจุบัน

```text
ผู้ช่วยค้นข้อมูลหลักสูตร — โหมดฐานข้อมูลจริง
┌────────────────────────┬───────────────────────────────────┐
│ เลือกหลักสูตร / ฉบับ    │ คำตอบและหลักฐาน                   │
│ คำถามภาษาไทย           │ idle → loading → success / error  │
│ [ถามข้อมูลหลักสูตร]     │ shared / track / plan sections    │
│ คำถามตัวอย่าง L1–L3    │ PDF page / printed page / link    │
│                        │ engine / server / request timing  │
└────────────────────────┴───────────────────────────────────┘
คำถามล่าสุด — เฉพาะ session
```

ความกว้างต่ำกว่า 1040px ซ้อนแบบฟอร์มกับคำตอบตามลำดับ desktop ยังคงสอง panels; ตารางของแต่ละแผนไม่เรียงสาม track แนวนอนจนชื่อวิชาอ่านไม่ได้ ข้อมูลและลำดับแผนมาจาก API ไม่ใช่ wireframe สถานะทั้งห้าตรวจผ่านแอปจริงตามรายงาน ไม่ใช้ placeholder response เป็นหลักฐานความถูกต้อง
